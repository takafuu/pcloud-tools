# 報告

## 現状

- `pcloud-manager` は `help` / `help --ai` / `info` / `status` / `doctor` を備えた public CLI として稼働中。
- pushd は launchd resident + bounded upload executor が稼働中。executor は `--max-records 10`, `PCLOUD_TOOLS_TRANSFER_EXEC_TIMEOUT_SECONDS=3600`。
- diffd は launchd API polling + bounded download executor が稼働中。executor も timeout 3600。
- live queue は clean: pushd planned/missing/manual-review 0、diffd planned/remote/manual-review 0。
- `normal sync/resync`, listing cache operations, autosync launchd changes はこの daemon flow では触らない運用 invariant のまま。

## 完了

- pushd/diffd daemonization は preview-first / human-gated で launchd 登録、resident plist、reload、bounded executor まで完了。
- diffd は account-wide `/diff` 履歴を checkpoint し、以後の新規 remote change を queue/download できる状態。
- upload/download executor は成功時のみ record consume、失敗/timeout/manual-review は保持する方針。
- download suppression / upload origin journal を追加し、local upload echo と download echo を抑制。
- download 中に local same-path が変わった場合は local を保持し、download 済み内容を `*.conflict-YYYYMMDD-HHMMSS.*` に退避する conflict copy を実装・実機検証済み。
- abnormal Discord notify を追加し、同一 `service + kind + path` は既定 3600 秒 dedupe。
- missing local upload records を通常 cleanup surface にし、xbar-safe action と public gated prune を追加。
- `.pcloudmanagerignore` を追加。`!` 行は例外許可ルール。`.env` は除外、`.env.sample` / `.editorconfig` / `.keep` は許可。`.partial` は hard safety exclude のまま。
- `info`, `info paths`, `info config` を追加。`info config` は token と gate env を redacted 表示。
- (refactor) `cli_common.py` に helper 12 関数を集約。10 cli_* モジュールの重複定義消滅。
- (refactor) `download_suppression.py` を `JournalKind` 経由の単一実装に統合。`atomic_write_json` 化。
- (refactor) `io_utils.py` に `atomic_write_json` / `atomic_write_text` を追加し、journal / daemon_state / cli_service_daemon / cli_archive / cli_mode / cli_sync の raw `write_text(json.dumps)` をすべて置換。crash protection テストあり。
