- pushd/diffd は read-only real-operation gate (`pushd gate`, `diffd gate`) まで追加済み。pushd は fixture-backed fswatch parser (`pushd fswatch preview --fixture <path>`) と one-shot fswatch probe preview (`pushd fswatch probe`)、diffd は fixture-backed pCloud diff parser (`diffd diff preview --fixture <path>`) と API poll request-shape preview (`diffd api-poll preview`) も追加済み。diffd planned downloads には allowlist/default-exclude policy を適用済み。transfer は `pushd transfer preview` / `diffd transfer preview` で `rclone copyto` argv を出し、`pushd transfer check` / `diffd transfer check` は real transfer gate 前の read-only checklist を出す。`transfer check` は `--confirm-path` / `--confirm-direction` / `--consume-policy` / `--timeout-policy` で first real run の operator/reviewer confirmation を read-only に記録でき、`--final-review` で ready 時だけ display-only の dry-run command と exact real command を表示できる。blocked 時は不足 check を列挙し、transfer command strings は出さない。ready 時も `ready-for-separate-gate` であり、実 transfer execution が使える意味ではない。`pushd transfer real-gate` / `diffd transfer real-gate` は別 real execution gate の read-only scaffold で、`PCLOUD_TOOLS_REAL_TRANSFER_EXECUTION_GATE=operator-approved-real-transfer-v1` を要求し、fake-rclone gate reuse forbidden を返す。approval flags が揃うと `complete-read-only` になるが real-gate 自体は実行しない。operator verification required は read-only report に表示され、通常の read-only diagnostics は自動検証だけでよく、人間確認は first real target / real execution gate / actual pCloud-rclone transfer に寄せる。human gate status も機械判定でき、service gate は `required-before-real-work`、real-gate approval complete は `required-before-actual-transfer` を返す。future real-run policy は read-only に文書化済みで、成功時だけ該当 record を消費し、失敗/不明時は保持し、自動 rollback/delete はしない。`pushd transfer real-run --execute` / `diffd transfer real-run --execute` は guarded real execution path になり、final-review 引数、approval flags、専用 real gate env、non-`fake-rclone` の `PCLOUD_TOOLS_RCLONE_BIN`、`--execute` が揃うまで error / state writes none。成功時は `last-transfer.json` に mode `real-rclone-transfer` を記録するが queue/change record は自動消費しない。`pushd transfer run --execute` / `diffd transfer run --execute` は dev-state + `PCLOUD_TOOLS_TRANSFER_EXECUTION_GATE=dev-fake-rclone` + `.dev-state/.../fake-rclone` のテスト実行だけ許可する。fake-rclone 実行には `PCLOUD_TOOLS_TRANSFER_EXEC_TIMEOUT_SECONDS` の timeout が入り、timeout 時は fake process group cleanup を試み、成功/失敗は `last-transfer.json` に記録する。fswatch 常駐、pCloud API long-poll、実 pCloud upload/download、launchd はまだ開いていない。
