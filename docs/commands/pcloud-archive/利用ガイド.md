# pcloud-archive 利用ガイド

Last updated: 2026-08-28

## 何をするコマンドか

`pcloud-archive` は、設定したローカルフォルダから `pcloud-crypt:` へ、rcloneで直接ファイルを一方向コピーする手動CLIです。cryptのマウントは不要です。

```text
設定したローカル source_root
        ↓ rclone copy
pcloud-crypt: 内の remote_root
```

不足または変更されたファイルをコピーします。ローカル側でファイルを削除しても、pCloud側からは自動削除しません。双方向同期や `rsync --delete` ではありません。

`pcloud-archive`は`pcloud-tools` releaseに含まれます。GitHub installerでuvの隔離runtimeへ導入され、public wrapperはdevelopment checkoutを参照しません。install方法は`https://github.com/takafuu/pcloud-tools`のREADMEを参照してください。

## 最初に設定する

設定ファイルは `~/.config/pcloud-archive/config.toml` です。`source_root` には実際のコピー元を、`remote_root` にはcrypt内の保存先を指定します。`~/p-crypt` や `~/.pcloud/crypt` はコピー先のマウント表示なので、`source_root` には指定しません。

必要なキーと書式は `pcloud-archive help config` で確認できます。初期ファイルを作る場合は次を実行します。既存ファイルは上書きしません。

```sh
pcloud-archive help config --init-config ~/.config/pcloud-archive/config.toml
```

作成される `source_root` は空です。実在するローカルディレクトリへ書き換えてから `pcloud-archive doctor` を再実行してください。

```toml
[defaults]
profile = "mac"

[profiles.mac]
source_root = "/absolute/path/to/local/archive-source"
remote_root = "pcloud-crypt:archive"
```

crypt直下へ保存する場合は `remote_root = "pcloud-crypt:"` とします。初回は小さいサンプルと `pcloud-crypt:_pcloud-archive-dev` のようなsandboxで確認してください。

## 基本ワークフロー

```sh
pcloud-archive doctor
pcloud-archive diff
pcloud-archive promote . --dry-run
pcloud-archive promote . --execute
pcloud-archive check . --execute
```

- `doctor`: 設定、ローカルコピー元、rclone、crypt remote到達性を診断する。
- `diff`: ローカルとcryptを読み取り専用で比較する。
- `promote`: `rclone copy` をプレビューまたは実行する。
- `check`: `rclone check --one-way` で検証し、成功時にmanifestを記録する。

特定のサブフォルダだけを扱う場合は、`source_root` からの相対パスを渡します。

```sh
pcloud-archive promote Photos/2026-07 --dry-run
pcloud-archive promote Photos/2026-07 --execute
pcloud-archive check Photos/2026-07 --execute
```

## cryptマウントとの関係

`pcloud-manager mount crypt --execute` で作る `~/p-crypt` はFinderから閲覧・手動コピーするための任意UIです。`pcloud-archive` はマウントを経由せず、rcloneの `pcloud-crypt:` remoteへ直接接続します。cryptが未マウントでも処理できます。

## あとで使い方を思い出す

```sh
man pcloud-archive
pcloud-archive --help
pcloud-archive help --detail
pcloud-archive info paths
pcloud-archive info config
```

`man pcloud-archive` は用途、初回設定、標準手順、安全性をまとめた短い概要です。man pageのsourceは `/Users/takafumi/p-core/dev/pcloud-tools/docs/man/pcloud-archive.1`、インストール先は `/opt/homebrew/share/man/man1/pcloud-archive.1` のsymlinkです。

`help --detail` はman page、説明書ディレクトリ、文書一覧、`cd` / `ls -1` / `open` の例を表示します。`info paths` はpublic command、実装、config、state、log、man page、説明書の実パスを表示します。

config fileが存在しない場合、`doctor` と `info` は長いTOML例を展開せず、`pcloud-archive help config` と `pcloud-archive help config --init-config <config_path>` への短い誘導を表示します。

説明書ディレクトリはpublic commandまたは実装ファイルの場所から `dev/#仕様書/pcloud-archive/` を探索します。通常は設定不要です。移設時だけprofileの `docs_dir` または `PCLOUD_ARCHIVE_DOCS_DIR` で上書きできます。

## 削除と制限

- ローカル削除はpCloudへ自動反映されません。
- pCloud側の単一ファイル削除は `delete-canonical` だけが担当し、成功時にtombstoneを記録します。
- `drop-cache` は現在preview-onlyです。
- `diff` のsame/different判定は現在サイズベースです。同一サイズの内容変更は区別できないため、最終確認には `check` を使います。
